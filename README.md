# Projects

A static site hosted on GitHub Pages. Each project lives in its own folder.

## Structure
- `index.html` — the projects hub (the home page)
- `portola-2026/` — Portola 2026 festival lineup page

## URLs (after enabling GitHub Pages)
- Hub:      https://USERNAME.github.io/
- Portola:  https://USERNAME.github.io/portola-2026/
(If you used a normal repo named e.g. "projects", add /projects in front:
 https://USERNAME.github.io/projects/portola-2026/)

## Adding a new project
1. Make a folder (e.g. `my-next-thing/`) containing an `index.html`.
2. Upload the folder to the repo.
3. Add a card linking to it in the hub `index.html` (template is in the file's comments).
